# Histórico — Azul Hermes

Esta pasta preserva o CSS e o HTML completos imediatamente anteriores à identidade Bio-Tech Solar. `cores.json` registra as variáveis da versão azul. O PDF azul continua em `divulgacao/smart-solar-tree-paleta-azul.pdf`.

## Restaurar

Na raiz do projeto:

```powershell
Copy-Item -LiteralPath 'historico/2026-09-25-paleta-azul/styles.css' -Destination 'styles.css'
Copy-Item -LiteralPath 'historico/2026-09-25-paleta-azul/index.html' -Destination 'index.html'
```

Recarregue com Ctrl+F5. Esses comandos restauram os arquivos inteiros desta versão; preserve alterações posteriores antes de executar.
